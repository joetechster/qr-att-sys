{% comment %} Live criteria checklist, driven by static/js/password_meter.js. Mirrors AUTH_PASSWORD_VALIDATORS except CommonPasswordValidator, which needs Django's list of ~20,000 leaked passwords and so cannot run in the browser. Hence "Checks so far" and the footnote — a full set of ticks is progress, not a guarantee that the server will accept the password. {% endcomment %}

Checks so far

  • At least 8 characters
  • Not only numbers
  • Not similar to your name or username
  • Both passwords match
Very common passwords are also rejected when you submit.
